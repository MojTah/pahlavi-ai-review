## Prospective assessment

Generate at most twelve first outputs, one per fixed case/condition. Same checkpoint, numerical path, decoding, template and output cap for all arms; no automatic retries or silent truncation. Actual frozen template/tokenizer check: maximum **887 prompt tokens**, plus256 output tokens within2,048. This is local capacity evidence, not a cloud runtime or latency test.

Two condition-blind assessors judge each output against the qualified reference and the declared source constraint. Store condition mapping separately from rating packets. AI agreement is provisional, not two specialist measurements. Use the same definitions in A/B/C:

- **SUPPORTED:** the output expresses the relevant event/list/relation and satisfies the complete primary constraint. Berk.25 allows an unnamed/omitted subject in an otherwise expressed `dād` event; this does not allow omitting the event itself.
- **CONTRADICTED:** an expressed relation reverses, replaces or violates that constraint.
- **OMITTED:** the event or relevant relation is absent or the output abstains; it earns no support credit.
- **UNRESOLVABLE:** reference/output interpretation conflict prevents a qualified judgment. Hold that case's comparison; never count it as correct.
- **FAILED_OUTPUT:** runtime failure, empty answer or truncated completion. Keep the fixed attempted denominator; do not replace the case.

Record scoped critical errors separately: reversed patronymic; invented/incorrect named giver; replaced witness/sealer or unsupported title asserted as certain; collapsed plural referents or invented list elements. Unassessed fields are neither correct nor incorrect by default. A clearly unsupported assertion within a declared safety field remains a scoped error, even if that field is outside the primary score.

Accept source-qualified synonyms when the constraint is preserved: for example, plural `ناحیه‌ها` for `rōstāg` need not copy the Persian reference's `روستاها`. Preserve both distinct list elements. A dictionary-listed alternative by itself does not establish contextual equivalence: Zand's reference supports places and villages/districts, not automatic acceptance of the river-bed homograph; genuine reading/reference disagreement is UNRESOLVABLE. An absent title in a reference is not affirmative evidence that an output title is wrong; use the source's documented uncertainty, otherwise record UNRESOLVABLE for that safety field. A missing verb/inventory binding can confound a negative result: failure to express a predicate does not isolate failure to use participant analysis. C supplies the scored relation, especially kinship in Kanheri; success establishes evidence use, not independently discovered meaning.

Report four case-by-case A/B/C judgments and disagreements. Primary contrast C versus B; secondary B versus A. Do **not** apply the old whole-passage acceptance denominator or two-net-acceptance screen. Consistent safer C improvements would justify considering a larger qualified panel; no gains, disagreements, one-family dependence or new scoped critical errors require resolving that specific issue. No statistical significance, model promotion, automatic training or sweep follows from four results.
