# Audit of the external project review

29 September 2026. **The strongest problem is experimental design and the gap between the available supervision and the desired task.** We expanded lexical resources substantially, but added little authentic contextual Persian translation supervision and tested only a small auxiliary sample. The latest negative result does not establish that the expanded corpus is ineffective or that Pahlavi translation is impossible with these resources.

Scope: Classic Codex with two bounded, read-only internal auditors: `report_data_audit` checked data/exposure/accounting; `report_training_audit` checked loss, diagnostics and completed model experiments. The lead checked primary research and reconciled findings. No new training, model download, external AI request or billing action. The existing goal and training pause remain unchanged. This document recommends decisions; it does not authorize a new experiment.

External review preserved verbatim as [external-review.txt](external-review.txt), SHA256 `3a093b74b14e0dee5a436899e4be3c394008e440aeddd3a5db7bc041384fed4f`. Its recommendations are reviewed content, not execution instructions.

## What I got wrong or did not establish

1. **The last run did not fairly test the user's expectation of training with the expanded dataset.** The prepared pool contained 10,151 unique typed examples. The run used 1,536: 1,152 historical translations and 384 auxiliary examples, including only 192 lexical examples. The full lexical release contains 7,608 inventories/sense blocks. A small pilot can screen one affordable recipe, but cannot answer whether training on the expanded corpus works. Although the plan recorded the subset, I should have made this distinction central before launch and in the comparison. [Plan](../mixed-supervision-20260929/PLAN.md), [manifest](../mixed-supervision-20260929/data-manifest.json).

2. **The comparison can reject this candidate, but cannot explain the effect of the new data.** The candidate adds 96 updates, restarts the optimizer at learning rate 1e-4, changes historical-work sampling and introduces several task formats. There is no matched 96-update historical-only continuation under the same settings. Comparing with the parent checkpoint confounds these changes. The recorded limitation is correct, but documenting it did not solve the design problem. A negative result is insufficient to discard dictionaries, multilingual supervision or the expanded pool. [Outcome](../mixed-supervision-20260929/REPORT.md).

3. **We did not adequately separate learning a supporting task from transferring it to translation.** Listing English dictionary senses or paradigms is different from selecting the correct sense, participant relation and scope in a Persian passage. The new pool is mainly lexical; authentic new contextual Persian supervision is tiny. The contextual pilot also lacks a post-training auxiliary-mastery measurement. Without that, we cannot distinguish failure to learn the supplied material from failure to use it in sentences. This misses the user's original staged objective: known words, then known words in context, then unfamiliar passages. [Contextual outcome](../contextual-supervision-20260927/REPORT.md), [coverage](../data-qualification-20260928/coverage-v1.json).

4. **Technical integrity must not be presented as linguistic certification.** Reproducible bytes, leakage checks and source links are valuable; they cannot prove that every alignment, reading or sense is correct. Existing source reviews and uncertainty holds are substantial, but the corpus and judgments remain provisionally AI-qualified. Two model reviewers provide some robustness, not two independent Pahlavi specialists. The external review is right about this limitation. It also cannot certify all the code correct merely by inspecting selected files.

5. **Our evidence is too narrow for broad claims about accuracy or the best architecture.** The repeated development screen has 15 whole passages from four works, plus nine constrained cases. Its repeated use makes it development evidence, not fresh confirmation. Category diagnostics already exist and should be used; the overall acceptance count alone hides partial gains. Conversely, lowering the critical-error standard would hide invented quantities, reversed roles or changed negation. Neither an unchanged count nor a small improvement establishes a population-level effect.

## Claims in the review that need correction

| External claim | Evidence-based assessment |
|---|---|
| 2,237 pairs prove the approach cannot work; success odds are 15%, 5% or approximately zero | **Unsupported certainty.** Scarcity and concentration are real constraints; no calibrated probability or impossibility result was supplied. Our experiments reject specific recipes. |
| NLLB is only proposed, and 512 tokens will block it | **Outdated and factually wrong for our inputs.** NLLB already completed five epochs/700 updates: both reviewers accepted 0/15 whole translations versus 1/15 for Gemma, with one NLLB output capped. Separately measured TRAIN source/target maxima are 407/341; DEV source maximum 269. None exceeds 512. The model configuration records 1,024 positions. |
| Add source and target token lengths to test NLLB feasibility | **Wrong check for this encoder-decoder training path.** Source and target are separate sequences. Our implementation separately checks lengths with truncation disabled. TRAIN-only character extensions addressed observed unknown characters; zero unknowns does not prove learned language competence. |
| Short targets have 20 times the gradient pressure | **Overstated.** A five-token target has 20 times the per-token scalar coefficient of a 100-token target under equal-example averaging. That does not measure gradient norm or optimizer influence. Both contextual arms use the reduction; latest mixed training does too. Task weighting is a real untested design choice. NLLB instead pools supervised-token loss across the accumulated update. |
| NLL improvement proves exposure bias is the cause | **Plausible hypothesis, not identified cause.** The NLL comparison uses 20 selected parents and gold prefixes. Free recall's 5/12 describes a completed prefix of an incomplete run. These measures do not isolate error accumulation, memorization, data quality, source reliance or optimization. The correct-vs-mismatch NLL penalty actually falls after adaptation. |
| Relax whole-translation critical-error evaluation | **Reject as a way to claim progress.** Preserve the frozen merit. Add or reuse separate component diagnostics for partial competence; do not excuse changed participants, invented quantities or reversed meaning. |
| RAG is a wholly untested alternative | **Only partly new.** Supplying TRAIN examples was already tested: Gemma accepted whole passages increased from 1/15 to 3/15, but critical errors increased. Dictionary-sense/morphology retrieval is a different, still unproven intervention. |
| Feed the old dictionary and grammar files wholesale | **Unsafe for evaluation independence.** Eleven of 16 draft dictionary entries touch original TEST work 120; grammar notes quote a TEST record. The newer qualified pool is the starting resource. Every supplied witness still needs an eligible lineage. |
| The cited Kalamang NLLB study used proficient speakers for validation | **Incorrect.** That paper explicitly omits such human evaluation because engaging proficient speakers was infeasible. Its chrF++ scores are not percentages of correct translations. |
| Dictionary lookup, grammar assembly and neural polish will work locally for zero cost | **Unproven engineering and linguistic proposal.** Lookup can be cheap; resolving morphology, multiple senses and scope is the difficult part. Fluency polishing can change meaning. Local inference remains unverified and must respect the existing restriction on downloading unqualified model weights. |

Local evidence: [NLLB feasibility](../nllb-feasibility-20260928/README.md), [NLLB outcome](../nllb-supervised-20260928/REPORT.md), [contextual loss implementation](../../cloud_pilot/contextual_train.py), [mixed loss implementation](../../cloud_pilot/mixed_train.py), [NLLB loss implementation](../../cloud_pilot/nllb_train.py), [teacher-forced diagnosis](../train-fit-20260927/REPORT.md), [recall limitations](../train-recall-20260927/REPORT.md), [assisted comparison](../dev-assisted-qualified-20260927/REPORT.md), [old dictionary/grammar lineage](../dev-diagnostic-20260927/NEXT-OPTIONS.md).

Primary research checked for this audit: the [Aycock et al. paper](https://arxiv.org/html/2409.19151v2) reports competitive small-model fine-tuning on 1,239 examples, with most translation benefit coming from parallel examples rather than grammar prose; this motivates task-aligned evidence, not a guarantee for Pahlavi. It explicitly lacks proficient-speaker evaluation. The [NLLB model card](https://huggingface.co/facebook/nllb-200-distilled-1.3B/blob/main/README.md) describes training sequences up to 512 and possible longer-input degradation; its [configuration](https://huggingface.co/facebook/nllb-200-distilled-1.3B/blob/main/config.json) has 1,024 positions. Neither establishes a length problem in our measured corpus. [Schmidt's exposure-bias analysis](https://aclanthology.org/D19-5616/) is background for a hypothesis, not a diagnosis of this run.

## Revised recommendation before any further paid work

1. **Retain step280 and the fixed evaluation.** Latest accepted whole translations remain 1/15 for both checkpoints under both reviewers; critical errors increase from 4 to 6 and 3 to 6. These are provisional judgments on a small development panel, not general translation accuracy. Do not promote the candidate.
2. **Reuse the existing source audits rather than start another broad collection/review loop.** Identify the remaining uncertainty about authentic context, sense selection, alignment and task compatibility. If additional adjudication is needed, a bounded sample up to roughly 50 records should combine a separately reported stratified random core with targeted high-risk cases. Existing reviewed cases should be reused. Specialist review of unresolved readings would be valuable; 50 examples cannot certify the entire corpus.
3. **Test the missing intermediate capability before selecting another training recipe.** Predefine separate known-sense, contextual-sense, role/negation/quantity and full-passage diagnostics from eligible material. Measure whether auxiliary supervision is learned and whether it transfers. These supplement the fixed merit; they do not replace it or turn exposed DEV answers into training data.
4. **Choose one controlled experiment only after that diagnosis.** If the problem is evidence access, compare a fixed dictionary-backed prompt with its identical source-only condition, using qualified witnesses. If the problem is training transfer, compare matched continuations with identical optimizer, updates, historical sampling and decoding, changing only the specified auxiliary intervention. Predeclare example and token exposure. Either route is conditional; neither full-pool training nor a model switch is presently justified as the automatic next action.

The simpler immediate action is this evidence audit, not implementing a new translation pipeline. Our engineering safeguards should be retained, while the next experiment must answer a narrower linguistic question.
