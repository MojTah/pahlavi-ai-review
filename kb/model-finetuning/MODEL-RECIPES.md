**Do not infer:** rank 16, two epochs or this learning rate are optimal; the model reached its capability ceiling; or 16–17/40 AI acceptances are a population accuracy percentage. **Delivery remains open:** training quantization, export quantization and deployment quality are separate. A 31B model is not established to fit solely in 8 GB VRAM. ## Trainer implementation note

Gemma training uses a Transformers Trainer with explicit masking; the NLLB pilot uses its own explicit accumulated seq2seq loop. No TRL migration is needed to create this KB. If a future implementation uses TRL, `assistant_only_loss` requires a compatible template exposing generation spans; packing and truncation can change example boundaries. Verify the resulting labels and complete samples on the actual model. [Official SFT Trainer documentation](https://huggingface.co/docs/trl/en/sft_trainer). Library options are implementation tools, not evidence that one objective improves our translations.
